# BioGeoHR

Needs :: Laragon, Flutter, Laravel, node.js for React.js, android studio

check branch = git branch -a

putting in Github
git add <directory>

git push

testing
Laravel: cd Backend
php artisan serve --host=0.0.0.0 --port=8080

Flutter/Mobile: cd Frontend\Mobile
flutter run

React/web: cd Frontend\web
npm run start
